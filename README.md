# Helix Jump

## Project Overview

Helix Jump is a 3D arcade-style ball balancing and obstacle avoidance game developed using Unity and C#. The game challenges players to guide a continuously bouncing ball through a vertical helix tower by rotating the platforms and finding safe paths between obstacles.

The objective is to navigate the ball through gaps in the rotating platforms while avoiding dangerous pink sections. Players must carefully control the tower's rotation to ensure that the ball lands only on safe blue platforms and continues its descent.

## Game Objective

The main objective is to guide the bouncing ball through the helix tower and reach the bottom without touching any dangerous platforms.

Players must rotate the tower, identify available gaps, and position the platforms correctly to allow the ball to pass through safely.

## Gameplay Features

- Ball Bouncing Mechanics: The ball continuously bounces on the platforms.
- Rotating Helix Tower: Rotate the tower to change the position of platforms and gaps.
- Safe Platforms: Blue platforms allow the ball to land safely.
- Dangerous Platforms: Pink platforms cause the game to end when touched.
- Gap Navigation: Find openings between platforms and guide the ball through them.
- Obstacle Avoidance: Carefully rotate the tower to avoid dangerous sections.
- Game Over System: The game ends when the ball touches a dangerous pink platform.

## Game Controls

| Input | Action |
|---|---|
| Mouse Drag | Rotate the helix tower |
| Mouse Movement | Control the tower rotation |

## Game Rules

### Safe Landing

The ball must land on blue platforms to continue progressing through the helix tower.

### Dangerous Landing

Landing on a pink platform immediately ends the game.

### Progression

Find the gaps between the platforms and guide the bouncing ball through them to continue descending.

## Winning Objective

Successfully navigate the ball through the helix tower by avoiding all dangerous platforms and reaching the bottom.

## How to Run the Project

1. Clone or download this repository.
2. Install Unity Hub and a compatible Unity Editor version.
3. Open Unity Hub.
4. Select Add Project from Disk.
5. Choose the downloaded Helix Jump project folder.
6. Open the project in Unity.
7. Open the main game scene and press Play to start.
